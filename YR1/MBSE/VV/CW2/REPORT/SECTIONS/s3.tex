\subsection{V\&V Specification}
\begin{itemize}
    \item An initial V \& V system has been modelled to support the design of a battery electric ferry.
    \item Three test procedures have been defined that relate to three test contexts.
    \item These test contexts relate to parts of the physical architecture.
    \item A requirement hierarchy captures the functional and non-functional requirements, along with relating them to the verification methods and stakeholder needs.
    \item An extensive software model performs V \& V on requirements deemed most important, and enables exploration of the design space for future optimisation.
    \item Traceability has been maintained throughout the work, leveraging tools that model based systems engineering provides.
\end{itemize}

\subsection{Achievement of Aims and Objectives}

This work has achieved its objectives:
\begin{enumerate}
    \item An initial requirements set and physical architecture has been generated.
    \item Stakeholder needs have been identified and modelled, being related to the relevant requirements.
    \item Three test procedures have been defined, using tests contexts to parameterise the tests and enable testing across different design variable ranges.
    \item The verification plan has been defined, being informed by a VCM
    \item An initial FMEA analysis has been performed, identifying failure modes and their mitigations
\end{enumerate}

\subsection{Highlights and Recommendations}
Of particular note in this work are the software models generated, which give a high degree of confidence in the results.
Additionally, the test procedure definition is rigorous and when standards were available have been informed by them to build further trust in them.
It is recommended that analysis and software verification on the entire requirements set and design space be undertaken next, including a thorough literature review. 
Following that, discussion with stakeholders around requirements that need relaxing or modifying would result in a more compliant system whilst keeping costs minimal.
