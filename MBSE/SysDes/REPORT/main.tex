\section*{Abstract}
Unmanned Combat Air Vehicles have become increasingly useful in modern warfare.
There is however a lack of suitable UCAV for naval based operations in most militaries.
This paper identifies the need for a carrier-based fighter style multirole UCAV, and sets out a multi-objective design optimisation problem with a focus on aerodynamic performance.
It shows a traceable SysML model which informs all design decisions, and presents a set of optimal design variables which can then be implemented in more detailed design.
